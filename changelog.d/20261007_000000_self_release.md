### Added

- The template releases itself through **Prepare template release** and
  **Template release on merge**, which call python-project-template's
  reusable release workflows at `@v1`. Prepare collects the `changelog.d/`
  fragments into `CHANGELOG.md` and opens a release pull request; merging it
  tags the release, creates the GitHub release and starts `bump-v1.yml`.
  Every release so far was published before its changelog section existed,
  and bump-v1 refused it; cutting the changelog inside the release pull
  request removes that step. `bump-v1.yml` can now be started on a tag as well
  as by a published release, and on a dispatch it accepts only the newest
  final `v1.X.Y` tag, so `v1` only moves forward.

### Changed

- This repo's changelog is now written as scriv fragments under
  `changelog.d/`, one per pull request, so concurrent PRs no longer conflict
  on `[Unreleased]`. Generated projects are unaffected.
